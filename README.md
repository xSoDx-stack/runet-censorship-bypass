## 🚀 Что изменено и улучшено в «АнтиЧебурнет»

В отличие от оригинального репозитория, в этом проекте реализованы следующие ключевые доработки и архитектурные изменения:

### 1. ⚡ Полная миграция на Manifest V3 (MV3)
* **Архитектура Service Worker**: Устаревшие фоновые страницы (background pages) из Manifest V2 полностью заменены на современный `service-worker.js`.
* **Энергоэффективность**: Фоновый процесс автоматически выгружается из памяти при простое и мгновенно активируется по событиям браузера.

### 2. 🛡️ 100% Приватность и Zero-Telemetry
* **Удалены все трекеры и внешние обращения**: Вырезана передача какой-либо информации о браузере, пользователе или посещаемых сайтах.
* **Исключены DoH/DNS утечки**: Удалены фоновые DNS-запросы к сторонним серверам при открытии вкладок.
* **Локальная обработка**: Все списки, настройки, исключения и журнал диагностики хранятся и обрабатываются **строго локально** в браузере.
* **Удалена страница сбора согласий**: Устаревшая форма `pages/consent` полностью исключена за ненадобностью.

### 3. 🚀 Экстремальная оптимизация (0 мс задержки) для 33 000+ доменов
* **Устранение зависания при пробуждении (Cold-Start Fix)**: Ликвидирована задержка в 1.5–3 секунды при первом открытии расширения после простоя воркера.
* **Мгновенный рендеринг (0 мс)**: Каркас всплывающего окна отрисовывается моментально без ожидания асинхронных ответов фонового процесса.
* **Отказ от глубокого клонирования объектов**: В PAC-движке устранено тяжёлое копирование `Object.assign` по 33 000+ свойствам (заменено на передачу по ссылке, $O(1)$).
* **Кэширование статистики**: Подсчёт количества сайтов (`pac-exception-stats`) сохраняется в хранилище и считывается за 0.01 мс без повторного перебора массива ключей.

### 4. 🌐 Умное автодобавление доменов
* **Автоподстановка активного сайта**: При открытии окна во вкладке «Сайты» автоматически подставляется корневой домен текущей веб-страницы.
* **Фильтрация системных URL**: Игнорируются служебные страницы браузера (`chrome://`, `edge://`, `about:`, расширения и локальные IP-адреса).
* **Автопокрытие всех поддоменов**: Добавление домена автоматически проксирует все его поддомены (`*.domain.com`).

### 5. ⚙️ Реактивное автосохранение настроек
* Все переключатели параметров во вкладке «Опции» сохраняются **автоматически в реальном времени** с визуальным toast-уведомлением. Ручная кнопка «Сохранить» упразднена.

### 6. 🎨 Современный Glassmorphic Dark UI & HiDPI-иконки
* **Тёмная тема**: Интерфейс выполнен в современном стиле тёмного матового стекла.
* **Увеличенный логотип**: Логотип в шапке окна увеличен до **40×40 px** со скруглением и неоновой подсветкой.
* **Полноразмерные иконки в браузере**: Иконки расширения (16, 32, 48, 128 px) перерисованы с обрезкой пустых полей — значок на панели инструментов занимает **100% доступной площади**.

### 7. 📋 Встроенный локальный журнал сбоев и диагностика
* Встроен раздел мониторинга ошибок прокси-серверов и PAC-скриптов с поиском, фильтрацией по категориям и возможностью экспорта отчёта.

### 8. 🧹 Тотальная очистка кодовой базы от устаревшего кода
* Удалены неиспользуемые скрипты Manifest V2 (`00-*`, `11-*`, `12-*`, `13-*`, `15-*`, `35-*`, `37-*`, `70-*`, `75-*`).
* Удалены устаревшие вспомогательные папки `src/extension-mini`, `src/extension-full`, старые тесты 2018 года и неиспользуемые конфигурации Webpack/React.
* Сборка сведена к единому чистому процессу в папку `build/extension-full`.

## 📥 Установка

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/anticheburnet.git
   ```
2. Откройте страницу расширений в браузере: `chrome://extensions/` (или `edge://extensions/`).
3. Включите **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку:
   ```text
   runet-censorship-bypass/extensions/chromium/runet-censorship-bypass/build/extension-full
   ```
