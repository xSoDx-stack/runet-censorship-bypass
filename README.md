**АнтиЧебурнет** — расширение для браузеров на базе Chromium (Google Chrome, Microsoft Edge, Brave, Яндекс.Браузер, Opera, Vivaldi), обеспечивающее выборочное проксирование заблокированных ресурсов на основе PAC-скриптов и пользовательских правил.

### Краткое описание проекта
Расширение перенаправляет через прокси только те сайты, к которым ограничен доступ (или добавленные пользователем), оставляя остальные сайты на прямом подключении (DIRECT). Все правила маршрутизации компилируются и исполняются локальным PAC-движком непосредственно в браузере.

## 🚀 Основные возможности и изменения

### 1. Архитектура Manifest V3 (MV3)
* **Service Worker**: Фоновые страницы Manifest V2 заменены на модульный `service-worker.js`.
* **Энергоэффективность**: Процесс работает по событиям и выгружается из памяти в периоды неактивности.

### 2. Отсутствие телеметрии и внешних трекеров
* **Удалены аналитика и счётчики**: Полностью вырезана передача данных о браузере, пользователе и посещаемых адресах.
* **Удалены фоновые DoH-запросы**: Исключены сторонние обращения к DoH/DNS-серверам при открытии вкладок.
* **Удалена страница согласий**: Устаревшая форма сбора разрешений удалена из проекта.
* **Локальное хранение**: Настройки, списки исключений, прокси и журнал диагностики хранятся исключительно в `chrome.storage.local`.

### 3. Выбор PAC-источников и свой PAC по ссылке (Custom PAC URL)
* **Готовые источники**: Поддержка скриптов «Антизапрет», «Антицензорити» и режима «Только свои сайты».
* **Свой PAC по ссылке**: Возможность указать прямую ссылку на любой готовый PAC-скрипт (HTTPS/HTTP).
* **Единый конвейер обработки**: Пользовательские исключения, свои прокси и правила Proxy Or Die применяются поверх любого выбранного PAC-источника через единый компилятор `pacKitchen`.

### 4. Управление своими прокси и проверка доступности
* **Поддержка протоколов**: HTTP, HTTPS, SOCKS4, SOCKS5 (включая локальный Tor и WARP).
* **Авторизация**: Поддержка логина и пароля с разделением постоянных и временных учетных данных.
* **Health Check**: Встроенная проверка доступности прокси без рекурсивных вызовов в PAC-обёртке.

### 5. Режим «Proxy Or Die» (защита от утечки прямого IP)
* При включении режима запрещается падение в прямой `DIRECT`-доступ при сбое прокси для проксируемых ресурсов (fail-closed маршрутизация), при этом явно заданные пользователем исключения прямого доступа продолжают работать штатно.

### 6. Управление списками сайтов и исключений
* **Умное добавление**: Автоподстановка корневого домена активной вкладки с покрытием поддоменов (`*.domain.com`).
* **Исключение служебных адресов**: Автоматическая фильтрация внутренних страниц браузера (`chrome://`, `edge://`, `about:`) и локальных IP.
* **Импорт и экспорт**: Поддержка пакетного импорта и экспорта списков доменов в формате `.txt`.
* **Очистка категорий**: Возможность быстрой очистки списков проксируемых сайтов.

### 7. Оптимизация производительности и интерфейс
* **Быстрый запуск**: Устранена задержка при открытии всплывающего окна после простоя Service Worker.
* **Кэширование статистики**: Подсчёт элементов выполняется без блокирующих переборов массивов.
* **Автосохранение**: Настройки сохраняются в реальном времени.
* **Локальный журнал диагностики**: Просмотр событий, фильтрация по категориям и экспорт логов для локальной диагностики.
* **Тёмный интерфейс**: Адаптивный компактный интерфейс и чёткие HiDPI-иконки для панели инструментов.

### 8. Очистка кодовой базы
* Удалены устаревшие файлы и скрипты Manifest V2, неиспользуемые генераторы и зависимости.
* Сборка сведена к чистому процессу в каталог `build/extension-full`.

## 📥 Установка

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/xSoDx-stack/runet-censorship-bypass.git
   cd runet-censorship-bypass
   ```
2. Установите зависимости и соберите проект (при сборке из исходного кода):
   ```bash
   npm install
   npm run build
   ```
3. Откройте страницу расширений в браузере: `chrome://extensions/` (или `edge://extensions/`).
4. Включите **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
5. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку:
   ```text
   runet-censorship-bypass/extensions/chromium/runet-censorship-bypass/build/extension-full
   ```
